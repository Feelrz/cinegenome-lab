# Database notes

The project now supports three catalog layers:

1. **Local curated starter set** in `data/movies.js`.
2. **Curated 500 title pool** in `data/top500.js` (membership only, no ranking shown).
3. **Enriched Top-500 catalog** generated by `scripts/build-top500.mjs` into `data/top500-enriched.js` and `data/top500-enriched.json`.

For production, use `database/schema.sql` in Supabase/PostgreSQL. Keep canonical metadata in `movies` and the 12-dimensional CINEGENOME vector in `movie_dna`.

TMDB should be queried server-side for public deployments. Never expose a service-role Supabase key or a long-lived TMDB bearer token in frontend source.
